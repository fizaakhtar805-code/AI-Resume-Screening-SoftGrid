# AI-Powered Resume Screening System

An AI-based resume screening project built during my internship at SoftGrid Solutions.

## Project Overview
This project aims to build an intelligent resume screening system that automatically evaluates candidates and predicts whether they should be shortlisted for hiring — reducing manual HR effort and improving recruitment efficiency.

## Day 1 — Dataset Collection & Research
- Researched Applicant Tracking Systems (ATS) and how modern resume screening works
- Collected dataset from Kaggle: AI-Driven Resume Screening Dataset by Sonal Shinde
- Defined project scope, problem statement, and objectives
- Identified input features and expected output

## Dataset
- **Source:** Kaggle (CC0 Public Domain)
- **File:** `ai_resume_screening.csv`
- **Size:** 945 KB
- **Columns:** years_experience, skills_match_score, education_level, project_count, certifications, interview_score, shortlisted
